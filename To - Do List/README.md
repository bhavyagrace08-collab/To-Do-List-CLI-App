# To-Do List CLI Application

## 1. Project Overview
The To-Do List CLI Application is a simple task management system developed using Python. It allows users to add, view, and remove daily tasks through a command-line interface.

The application also saves tasks in a text file so that users can access their tasks even after restarting the program.

## 2. Objectives
- To develop a simple task management application.
- To understand Python lists and functions.
- To implement adding, viewing, and removing tasks.
- To understand file handling in Python.
- To store and retrieve tasks permanently.

## 3. Features
1. Add new tasks.
2. View all tasks with serial numbers.
3. Remove tasks using task numbers.
4. Display a menu-driven interface.
5. Save tasks in a text file.
6. Load previously saved tasks.
7. Handle invalid inputs.

## 4. Technologies Used
- Programming Language: Python
- IDE: Visual Studio Code
- Storage: Text File
- Concepts: Lists, Functions, Loops, Conditional Statements, Exception Handling, and File Handling.

## 6. How to Run the Project

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Execute the following command:

```bash
python todo.py
```
